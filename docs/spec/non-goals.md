# Non-goals

Out of scope for now. Revisit by editing this file.

- **Layers** as a user-facing concept (items have a z-order, but there is no layer panel).
- **Painting or drawing** tools that add new color. The smear tool (`product/retouch.md`)
  only moves and blends an image's own pixels.
- **Windows and macOS** support.
- **Web or JavaScript-based UI** of any kind (see constitution).
- **Embedding image data** in project files; projects hold references only.
- **Choosing a license**; deferred.
